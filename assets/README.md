# Assets

No logo is used in this app (the placeholder was removed at the owner's
request, Nov 10 2026). This folder is kept for any future image assets.

Fonts: Alternate Gothic Extra Condensed ATF and Proxima Nova are licensed
and were not supplied, so the app uses the specified Arial fallbacks (see
`css/app.css`). If licensed font files are supplied later, drop them in this
folder and add `@font-face` rules at the top of `css/app.css`.
